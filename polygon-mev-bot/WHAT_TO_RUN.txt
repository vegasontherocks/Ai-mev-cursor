================================================================
WHAT TO RUN (ACCURATE as of October 2025)
================================================================

1. **Verify environment setup**
   ```bash
   cd /workspaces/Ai-mev-cursor/polygon-mev-bot
   cp .env.example .env        # replace every placeholder
   ```
   Required keys: `THIRDWEB_SECRET_KEY`, `THIRDWEB_CLIENT_ID`, `PRIVATE_KEY`, `POLYGON_RPC_URL`, `POLYGON_WSS_URL`, `POLYGONSCAN_API_KEY`.

2. **Install toolchains**
   ```bash
   foundryup
   cd scripts && npm install && cd ..
   cd eliza-agent-ai && npm install && cd ..
   cd eliza-agent && npm install && cd ..
   ```

3. **Attempt contract generation**
   ```bash
   ./GENERATE_NOW.sh
   ls contracts/src/generated
   ```
   Success criteria: the directory contains **six** files (`MEVExecutor.sol`, `DEXAdapter.sol`, `AaveAdapter.sol`, `JITAdapter.sol`, `OracleLib.sol`, `Interfaces.sol`). If any are missing, inspect the generator output and implement the adapters manually.

4. **Compile and test**
   ```bash
   cd contracts
   forge build
   forge test -vv
   ```
   Expand tests to cover the adapters before continuing. Do not deploy while tests fail or adapters are absent.

5. **Patch the agent**
   - Implement the real Thirdweb API calls in `eliza-agent-ai/src/services/thirdweb-nebula-integration.ts`.
   - Ensure `mcp-config.json` points to a reachable MCP server.
   - Provide `models/ppo_agent.onnx` or add download logic.

6. **Dry-run the pipeline**
   - Keep `DRY_RUN=true` and `ALLOW_EXECUTION=false` in all `.env` files.
   - Start the agent only after the API client and RL model are wired up.

7. **(Later) Deployment**
   ```bash
   cd contracts
   forge script script/DeployGenerated.s.sol \
     --rpc-url $POLYGON_RPC_URL \
     --broadcast \
     --verify \
     --etherscan-api-key $POLYGONSCAN_API_KEY
   ```
   Set `MEV_EXECUTOR_ADDRESS` everywhere and rerun tests against the live contract before unlocking execution.

================================================================
SHORT VERSION: nothing is turnkey. Validate each step, keep notes, and do not run live funds until every checkbox in `.github/copilot-instructions.md` is green.
